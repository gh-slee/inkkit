# README artwork and badges

`xteink-mark.svg` is original project artwork under the MIT license, retained for
InkKit from its XTEINK SD Migrator name. It depicts card migration and verification
and is not an XTEINK, CrossInk or CrossPoint logo. The historical asset filename is
kept; its accessible title identifies InkKit.
It contains no user data, photographs, screenshots, embedded fonts or external assets.

The CI badge reports the status of this repository's `main` workflow. Shields.io
badges are static labels for the documented Python/platform/dependency/license/version
status. They do not claim package downloads, coverage, popularity or hardware
certification. Badge images may contact their providers when the README is rendered;
the migration tool has no network dependency.

This named artwork and the separately reviewed [native screenshots](../macos/README.md)
are allowlisted for publication. New assets require
explicit source/provenance review and a publication-allowlist update. Never use
real backup contents, volume names, personal paths or book titles in previews.
