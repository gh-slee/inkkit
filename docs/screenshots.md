# macOS app screenshots

**Native app with synthetic example data.** Captured on 2026-10-24 from the local
ARM64 InkKit 1.0.0 development build, using the reviewed CrossInk 1.6.1 profile.
These are actual native windows/sheets, not generated mockups. Example names and
URLs are invented; no real SD card, books, network credentials or user settings
were used. Ancillary image metadata was removed without changing encoded image
data. The app is still an ad-hoc-signed development build, not a public GUI release.

The gallery documents UI behavior, not hardware certification. See
[validation and owner-reported X3 acceptance](configuration-validation.md),
[firmware/device support](firmware-support.md) and [preview instructions](macos-preview.md).
Most images show X3; the final Frontlight capture explicitly uses an X4 Pro demo.
Forms with more settings continue below the visible area.
